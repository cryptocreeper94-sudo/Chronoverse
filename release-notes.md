# 🌀 The Chronoverse v1.0.0

A free, ad-free, educational action-adventure platform built for kids aged 6–9. Screen time that builds cognitive skills.

## What's Included
- **Rift Locker & Economy**: New 5-tab store with dual-currency (Lumes ✦ and Shards 💎)
- **Rift Runner**: The core action-adventure experience across 9 unique worlds
- **Learn Mode & Create Mode**: Parent-child co-op and voice sandbox
- **Android Support**: Mobile APK build support added
